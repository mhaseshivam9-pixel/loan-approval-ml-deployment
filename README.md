
# Loan Approval Prediction System

A machine-learning based loan approval prediction application.

## Deployment

This project is deployed using Vercel and Flask.

## Machine Learning

Models evaluated:

- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine

Final deployed model:

Pipeline

Decision threshold:

0.49999999999999994

## Application

The application accepts applicant information and produces:

- Loan approval prediction
- Approval probability
- Decision based on the selected threshold

## Disclaimer

This application is an educational decision-support prototype.
It should not be used as the sole basis for real-world lending decisions.
